# Access Ready

Access Ready is an AI-powered cognitive accessibility tool that transforms dense course materials into structured, focus-friendly learning experiences.

## Problem

Students are often given dense lecture slides, PDFs, and course materials with high information density, weak hierarchy, competing visuals, and multiple concepts presented at once.

For students with ADHD, dyslexia, and other learning differences, this unnecessary cognitive friction can become a barrier to learning.

## Solution

Access Ready analyzes course materials and restructures them into a Focus View that presents one meaningful concept at a time while preserving the original academic content.

### Core Features

- PDF course material upload
- Focus barrier detection
- Structured concept extraction
- One-concept-at-a-time Focus View
- Key idea highlighting
- Expand/collapse detail controls
- Quick knowledge checks
- Links back to the original source

## Tech Stack

**Frontend:** React, TypeScript, Vite, Tailwind CSS  
**Backend:** Python, FastAPI, PyMuPDF  
**AI:** LLM-powered document analysis and concept restructuring with structured JSON

## Project Flow

PDF → Document Extraction → Focus Barrier Analysis → Concept Restructuring → Focus View → Quick Check
